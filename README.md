# ORION Live: descargas

Instaladores oficiales de ORION Live, las reuniones y webinars de ORION Network.

| Sistema | Descarga |
|---|---|
| Windows | [ORION-Live-Windows.exe](https://github.com/darioseul/orion-live-descargas/releases/latest/download/ORION-Live-Windows.exe) |
| Mac con chip Apple (M1, M2, M3, M4…) | [ORION-Live-Mac-Apple-M.dmg](https://github.com/darioseul/orion-live-descargas/releases/latest/download/ORION-Live-Mac-Apple-M.dmg) |
| Mac con procesador Intel | [ORION-Live-Mac-Intel.dmg](https://github.com/darioseul/orion-live-descargas/releases/latest/download/ORION-Live-Mac-Intel.dmg) |
| Android | [ORION-Live.apk](https://fxmastery-platform.vercel.app/live-apps/ORION-Live.apk) |

Se entra con el mismo correo o ID y la misma contraseña de la oficina de ORION Network.

**Windows:** si aparece «Windows protegió tu PC», toca «Más información» y «Ejecutar de todas formas».
**Mac:** la primera vez, clic derecho sobre ORION Live → Abrir → Abrir.
